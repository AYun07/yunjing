# 云境 · 二创版块

> 这里是云境玩家二创作品的展示与交换区。**云境主线源码完全由开发者维护，与本版块无关。**
> 本版块的作品由玩家自行发布，开发者不审核、不参与、不担责。

## ⚠️ 安全提醒（务必阅读）

- 本版块所有作品由**玩家自行上传**，云境开发者**不审核内容、不参与维护、不承担任何责任**。
- 下载、运行任何二创作品前，请**自行查看源码**，谨防病毒、恶意代码或数据窃取。
- 所有作品默认遵守**开源、非盈利**约定；如发现违规内容，请通过 GitHub 的举报渠道反馈。
- 请勿在作品中夹带 API 密钥、密码、个人隐私；发布时云境会自动扫描并拦截疑似密钥。

## 作品如何排列

- 玩家在云境内点击「工具 → 二创版块 → 发布我的二创」，确认开源非盈利、填写与原版的区别/更新后自动发布。
- 每条作品以 GitHub Issue 形式发布，带 `二创投稿` 标签，**按发布时间倒序排列**（最新的在最前）。
- 作品正文含：与原版的区别说明、作品包下载链接（玩家自己的公开 Gist）、基于的云境版本号。

## 作品包格式

- 作品包为 `.zip`，内含 `manifest.json`（作者/说明/版本/文件清单）与二创内容文件。
- 默认是**增量包**：只包含玩家改动的设定/模块/DLC/正则等，不含云境主线源码、不含存档正文、不含密钥。
- 桌面版 Chrome/Edge 授权项目目录后，可选择附加完整源码（包体较大，手机端不支持此选项）。

## 浏览与下载

- 在云境内打开「工具 → 二创版块」即可看到全部作品（按时间倒序），点击"下载作品包"或"原帖"。
- 也可直接浏览本仓库带 `二创投稿` 标签的 Issues。
