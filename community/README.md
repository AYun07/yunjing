# 云境 · 创意工坊（唯一作品区域）

> 本目录是云境玩家二创作品的**唯一区域**。主线源码由开发者维护，与本区域无关。
> 作品由玩家自行发布，开发者**不审核、不参与、不担责**。默认开源、非盈利。

## 唯一区域规约（v6.6.0 起，禁止分散）

**全部二创作品只放在 `community/works/` 这一个总文件夹**，不再有第二个存放点：

```
community/
  README.md                       ← 本说明
  works/                          ← 唯一作品根
    catalog.json                  ← 清单：所有作品元数据，按时间倒序（新在前）
    20261122-233000-剑来武夫增强/  ← 每件作品一个子文件夹，名字带时间戳＝按时间排
      README.md                   ← 四段式说明（① 简介 ② 特点 ③ 二创内容 ④ 打包源码）
      meta.json                   ← 机器元数据（标题/作者/时间/基线版本/包体哈希）
      package.zip                 ← 真二进制增量补丁包（与说明同处，可一键下载）
```

- `community/packages/`（v6.5.1 旧包体）与 `二创投稿` 标签的 Issues（v6.4.0 旧元数据）为**历史只读**：保留不删除，自 v6.6.0 起不再写入。
- 禁止新建第二作品目录、禁止用 Gist 分散存放；超大视频用外链写在特点里，不算分散。

## 每件作品固定四段结构（README.md）

四段按此顺序、此标记包裹，缺段视为不合规：

1. **简介**（`<!--YJ_INTRO-->`）：一句话概述作品。
2. **特点**（`<!--YJ_FEATURE-->`）：亮点列表。
3. **二创内容**（`<!--YJ_CONTENT-->`）：由系统自动比对基线生成的改动清单（改了哪些 DLC / 世界书 / 预设 / 存档等）。
4. **打包源码**（`<!--YJ_PACKAGE-->`）：作品文件夹路径、package.zip 文件清单、大小、哈希索引。

> 关于"打包源码"的准确含义：这里打包的是玩家在云境内改动过的**内容层明文数据**（`manifest.json` + `content/*.json`：DLC / 世界书 / 预设 / 插件定义 / 正则 / 存档 / 资源等），它们是"玩家可继续修改的源码"。**不是**云境主程序的 `.js` 文件——网页读不到玩家设备上的源码文件（手机尤甚），主程序始终归开发者。见 `DECISIONS.md` DR-051、DR-053。

## 玩家怎么用（全程在云境内，不必打开 GitHub 网页）

- **浏览 / 下载 / 安装**：云境 → 工具 → 创意工坊。清单从 `catalog.json` 读取，按时间倒序；每条有「⚡ 一键下载安装」，点一下即下载 package.zip、解包、三方合并（覆盖/合并/保留/冲突）、装前备份、可一键回滚。浏览/下载无需 token；首次需联网，断网读本机缓存。
- **发布**：创意工坊 →「＋ 发布我的二创」，填作品名 + 四段式前两段（简介/特点），系统自动生成二创内容与打包源码两段，打包后写入 `community/works/<时间戳>-<slug>/`（README.md + meta.json + package.zip）并更新 catalog.json。发布需玩家自己的 GitHub token（fine-grained 勾 Contents 读+写，或 classic public_repo），token 只存本机、永不入包。

## 安全与边界

- 所有作品由玩家自行上传，开发者**不审核内容、不参与维护、不承担任何责任**。
- 下载、运行前请自行查看 README 与包内明文（manifest + content/*.json），谨防夹带；违规内容走 GitHub 举报渠道。
- 发布会自动扫描并拦截 API 密钥 / 密码 / 隐私字段；存档默认剔除密钥。
- 云境是零后端静态应用：所谓"联通的文件夹"本质是 GitHub 公共仓库里的这个目录。匿名读有 GitHub 限流（约 60 次/小时/IP），故做了多线路容错 + 本机缓存；完全脱离 GitHub 的公共存储需要后端，不在本项目定位内。
- 单文件建议 < 20MB（GitHub contents API 上限 100MB）。大视频/大图走网盘外链。
- "打包源码"= 玩家改动过的内容层明文，**不是**云境主程序 `.js`（浏览器读不到设备磁盘源码，主程序归开发者）。
