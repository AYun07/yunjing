# 云境 · 二创版块（唯一区域）

> 本目录是云境玩家二创作品的**唯一区域**。主线源码由开发者维护，与本区域无关。
> 本区域作品由玩家自行发布，开发者不审核、不参与、不担责。

## 唯一区域规约（v6.5.1 起，禁止分散）

所有二创作品**只能**存在于以下两处，不得另立门户：

| 用途 | 唯一落点 | 说明 |
|---|---|---|
| 作品索引 / 简介 / 下载入口 | 本仓库带 `二创投稿` 标签的 **Issues** | 一件作品一个 Issue，按发布时间倒序 |
| 作品包体实体 | 本目录 `community/packages/` | 一件作品一个或多个 `.zip.b64`，不建子目录 |

**禁止**：新建其它标签归档二创、把包体传 Gist / 网盘 / 个人仓库、在别处另建列表。发布流程由云境内「工具 → 二创版块 → 发布我的二创」自动完成，玩家只点确认。

## 每件作品固定四段结构

Issue 正文按此顺序、此标记包裹，缺段视为不合规：

1. **简介**（`<!--YJ_INTRO-->`）：一句话概述作品。
2. **特点**（`<!--YJ_FEATURE-->`）：亮点列表。
3. **二创内容**（`<!--YJ_CONTENT-->`）：由系统自动比对基线生成的改动清单（改了哪些 DLC / 世界书 / 预设 / 存档等）。
4. **打包源码**（`<!--YJ_PACKAGE-->`）：包体在 `community/packages/` 的路径、文件清单、大小、哈希索引。

> 关于"打包源码"的准确含义：这里打包的是玩家在云境内改动过的**内容层明文数据**（`manifest.json` + `content/*.json`：DLC / 世界书 / 预设 / 插件定义 / 正则 / 存档 / 资源等），它们是"玩家可继续修改的源码"。**不是**云境主程序的 `.js` 文件——网页读不到玩家设备上的源码文件（手机尤甚），主程序始终归开发者。见 `DECISIONS.md` DR-051。

## ⚠️ 安全提醒

- 所有作品由玩家自行上传，开发者**不审核内容、不参与维护、不承担任何责任**。
- 下载、运行前请**自行查看包内明文**（就是第四段的 manifest + content/*.json），谨防夹带。
- 默认遵守**开源、非盈利**约定；违规内容请走 GitHub 举报渠道。
- 发布会自动扫描并拦截 API 密钥 / 密码 / 隐私字段；存档默认剔除密钥。

## 排列与浏览

- 在云境内「工具 → 二创版块」浏览，按时间倒序，四段信息一目了然。
- 也可直接看本仓库 `二创投稿` 标签的 Issues。
