# 云境 · 智能体技能

云境是一套纯前端的 AI 互动小说 + 开放世界扮演引擎，含 38 个世界。本技能让智能体（deepseekharness、Claude、各类 agent 框架）按云境的规则创作与跑团。

## 何时用

- 用户要"用云境的规则 / 某个世界的设定"写正文或跑团
- 用户提到具体世界名（剑来、斗破苍穹、诡秘之主、地球……）并要求符合原著
- 需要产出云境格式的正文：`正文 + (variable_update) 变量块 + 6 个行动选项`
- 需要防吃书：原住民不该知道的不能提前知道、不该出现的信息不能提前出现

## 核心规则（必须遵守）

1. **世界铁则优先**。每个世界有自己的 `configs/*-config.js`，其中 `fullSystemPrompt` 定义了铁则、众生相、负面清单、输出格式。动笔前先加载对应世界的设定（见下方 CLI）。
2. **防吃书 / 防全知**。角色只能知道自己身份该知道的信息。信息的揭示要符合演化逻辑，不是完全定死，但绝不能跳阶越境、提前剧透、让圣贤全知全能。
3. **输出三段式**。每轮回复必须包含：① 一章完整小说正文（无系统字样、无"作为AI"）；② `(variable_update)` 变量更新块（章节、字数、仪表盘、角色档案、伏笔、道具、状态、大事记）；③ 结尾 `【行动选项】` 给出恰好 6 个真正分岔的走向。
4. **界面提示不进正文**。变量、数值、提示只出现在变量块，绝不混进小说正文冒充结论。
5. **跨层倍率是估算**。跨世界战力对比一律标注"估算，仅供校准"，不写进正文当事实。
6. **边界护栏**。涉及未成年人的性内容、真实在世人物的不当描写一律拒绝；这是平台与法律红线，不因角色扮演而放开。

## CLI 用法

在云境仓库根目录运行（只需 Python 3，无第三方依赖）：

```bash
# 列出全部 38 个世界（代号 + 标题）
python3 plugin/yunjing-skill/yj.py list

# 导出某世界的完整设定（含铁则/负面清单/输出格式）为 Markdown
python3 plugin/yunjing-skill/yj.py world jianlai

# 导出某世界设定到文件
python3 plugin/yunjing-skill/yj.py world jianlai -o /tmp/jianlai.md

# 搜索所有世界里的某个设定关键词
python3 plugin/yunjing-skill/yj.py search "境界"

# 查看防吃书规则摘要
python3 plugin/yunjing-skill/yj.py rules
```

## 创作工作流

1. 用户给出世界名 → 用 `yj.py list` 确认代号。
2. 用 `yj.py world <代号>` 加载该世界铁则。
3. 若用户给了角色身份，按身份门控信息——只写这个身份能知道的事。
4. 按三段式产出正文；变量块用中文键名；结尾给 6 个选项。
5. 每轮把上轮的变量块当作世界状态的增量，保持账本连续，不凭空重置。

## 与云境本体的关系

本技能是云境的"外挂大脑"，不是云境本体。云境本体（纯前端 PWA）负责界面、存档、数值引擎、离线运行；本技能负责让外部智能体理解云境的世界观与输出契约，两者用同一套世界书与规则。世界设置以仓库 `configs/` 为准，技能不另造设定。
