# 云境 · 38 世界原著地点校对数据（ATLAS_VERIFIED）

## 目的
每个世界由独立子智能体联网查证原著后产出，覆盖**原著出现过的所有地点（含只提一嘴的）**，
并为每个地点标注：类别、所属区域/时代、**原著方位描述**、在地图上的坐标(x,y)、层级(lv)、出处。
取代此前 ATLAS_SUPPLEMENT 中"anchor 为空→hash 随机散点"的不合理落位。

## 输出契约（每个子智能体必须严格遵守）
- 文件：`js/atlas-verified/<worldId>.js`
- 格式：`window.ATLAS_VERIFIED = window.ATLAS_VERIFIED || {}; window.ATLAS_VERIFIED["<worldId>"] = { ... };`
- 对象结构：
  ```
  {
    name: "世界中名",
    source: "原著/作品名（用于披露）",
    note: "口径说明（如有跨时代/系列争议，在此写明）",
    eras: [   // 单时代世界也用长度为1的eras数组
      {
        id: "<worldId>_era1", name: "时代/位面名", era: "时期描述",
        places: [
          {
            n: "地点名",
            cat: "country|faction|sect|region|place",  // 五类分清
            rg: "所属区域",
            x: 0-100, y: 0-100,                        // 地图坐标
            lv: 0-4,                                   // 所在层级 0大陆/1区域/2地点/3子区域/4场景
            d: 1-5,                                    // 重要度（原著着墨）
            where: "原著方位描述原文，如'位于天斗城东南'",  // 关键：方位依据
            c: "《书名》章节/出处"
          }
        ]
      }
    ]
  }
  ```

## 硬验收句（子智能体自检）
1. 覆盖度：原著出现过的地点尽量收全（用户口径：哪怕只提一嘴也要写）
2. 方位可溯：每条有 `where`（原著方位描述）或注明"原著未明确方位，按相对关系推定"
3. 类别分清：国家/大型势力/宗门/地区/地点 不混
4. 层级合理：按地理尺度给 lv（大陆级0→场景级4）
5. 出处真实：c 字段标真实书名，不编造
6. 零语法错误：`node --check <file>` 通过
