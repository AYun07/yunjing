# 云境 · AI 互动小说 + 开放世界扮演

![云境封面](上架素材/商店宣传图-横版-封面.png)

> 打开网页就能用的 AI 互动小说加开放世界扮演。纯前端静态站，不用构建，没有后端，也不用注册账号。AI 接口自己填，故事和 Key 只留在本机浏览器里。封面只有一张，叫「万象入云」，四个入口进的是同一个世界。

## 一、云境是什么

云境把两件事缝进了一个网页。一件是跟 AI 一起写小说，另一件是跑一个会自己往下演的世界。两条玩法用的是同一套引擎。

**创作工坊**。设好视角、文风、时代、母题、开篇、技法和六维，跟 AI 一章章往下写，写完导出成 TXT 或 Markdown。

**开放世界扮演**。自己捏一个身份，姓名、出身、时代、资质、入场事件都自己定，然后踏进书里的世界随便逛。身份可以是原著主角，可以是原著配角，也可以完全原创。

它跟普通聊天机器人不一样。你说一句它续一段那种没有。每一轮 AI 写正文的同时，背后有一整套状态、地图、人物、势力、账本、时间线在跑，写完再把这些回灌进下一轮的提示词。世界会自己转，你做过的事会写回世界。

世界一共 38 个。原著同人 30 个，真实地球 1 个，自由创作 6 个，还有 1 个原创的网游大世界叫寰宇纪元，是失落叶网游三部曲合流来的。每个世界配一份自己的世界书和专名铁律表，按原著考据。这么做的目的很实在，就是防着小模型把人物写错、境界乱跳、宗门凭空冒出来。

这里说个数字上的疑点，免得有人对不上。代码里状态栏有 36 套专属状态字段，剩下 2 个自由创作界没有固定题材，用通用字段就够。所以「38 个能进的世界」和「36 套专属字段」是两码事，前者数的是世界，后者数的是字段表。

## 二、特色特点

### 世界和考据

- **世界自己会走**。世界时钟自转，NPC 的性格、理想、情绪会按结仇、势力覆灭、共同记忆慢慢变，变化有界，频率也压得低。势力兴衰、机缘、委托隔几天换一批。你做过的事会回写进世界。
- **按界考据，原著地点归位**。38 界各有各的世界书和专名铁律表。原著里的势力、国家、宗门、地点、地区，按原著方位和地理尺度摆到五级舆图上，不靠 hash 随机撒点。另外附了全世界地图一览图和逐世界的原著地名对照表，方便你自己核对。
- **多层可缩放舆图**。地名不会叠成一团，势力实时上图，你自己建的势力按驻地落图。五线深度下钻是独立挂上去的，不改动原来的东西。

### 数值和战力

- **数值白名单，默认卡死**。模型自己编的等级、金币、经验会被确定性地从正文里剔掉，你和 AI 看的是同一份账。严格演算是出厂默认，离谱的上报会被引擎截断，不指望模型自觉。
- **玩家例外，看得见**。你明确要求的时候可以按轮放行。拦截的原因会写成提示给你看，也会写回给 AI，让它下一轮别再犯。
- **跨层战力折算**。跨时代、跨体系能比，超神、道诡、帝霸、吞噬这些副轴都算进去了。倍率和折算规则全部标着「估算，仅供校准」，只写进报告，不写进正文。给不出跨层缘由的对比，一律判口胡。嵌套宇宙用独立的数据结构隔开，各算各的，不混轴。

### 记忆和回档

- **对话时光轴，任意楼层回档**。任何一轮都能回档、重 roll。回到某一层的时候，所有跟着剧情变过的数据一起退回去，退错了还能撤销。足迹、传承这类跨层内容默认不退，要退你勾一下就行。存档按固定 key 覆盖，不会越攒越大，另外有内存哨兵盯着。

### 模型和接口

- **不挑模型**。任何 OpenAI 兼容的端点都能填，官方直连、中转、自建网关、本地部署都行，没有白名单。接口档位先按接口特征和模型名猜一个，再按每轮的真实输出上下调，写得稳就升到全功能，开始复读就降到求稳，你也可以手动指定。
- **六个接口各干各的**。主笔只写正文。状态登记、远方推演、插图、润色插图提示词、手机分身交给别的模型去做。用哪几个、要不要混搭、留不留空，你自己配。
- **语义词缀引擎**。从固定词库查表改成语意解读加情境涌现，也能自己定义。本地解读即时保底，大模型在后台慢慢做深度解读，结果缓存好下次直接拿来用。调用走的是已经治理过的通道，成本和并发都控得住。

### 二创和工坊

- **云境内创意工坊**。所有二创只放在仓库的 `community/works/` 这一个文件夹里。每件作品一个带时间戳的子文件夹，里面是四段式 README（简介、特点、二创内容、打包源码）、meta.json 和 package.zip，说明和包体待在一起。按时间倒序，在云境里就能逛、能一键下载安装、能发布，不用去开 GitHub 网页。旧的 `packages/` 和 Issues 留着只读，既不写也不删。
- **增量补丁和三方合并**。二创只打包变化的那部分。PatchEngine 生成增量补丁，安装走 base、ours、theirs 三方合并，自动备份，失败能退回去。你没改过的项沿用基线，不算成删除。密钥在采集阶段就剥掉了。
- **小云造物中枢**。从造物入口进去，让小云按你的意思改源码、造文件、造模块、造插件、造 DLC、造原创设定并且应用。造物工坊、文件桥、插件运行时、研发中枢这四项本页就能用。

### 自由和边界

- **不被锁住**。预设、正则、世界书、原创设定、存档都能导进来、导出去，跟常见前端工具的预设格式整份互通。导出存档默认不带密钥，想换设备时省得重填，可以勾上明文。
- **零后端，Key 不上云**。不用安装，断网也能跑，是个 PWA。故事和 Key 只留在你本机。传二创要用你自己的 token，只存本机，不进包。

看过两组实测，数字放在这里。一组是 2026 年 11 月 9 日对着代码数的，38 界，世界书内置 24,940 条，玩家进界面板 32,312 条，通用常识库 194 条，专名铁律表 204 条，内置云起预设 86 块，正则 33 条，文风块 42 项。另一组是 11 月 20 日的真机跑测，38 个世界，每个大概 10 轮真实对话，总共 820 轮、1003 张截图，灵宠、检定、成长账本、词语加成、语义引擎、称号、装备、战斗这八个子系统都是 38 比 38 全过，主要面板交互也是全过，明细在[功能可用性对照表](云境-功能可用性对照表.md)。

## 三、能做什么

- 一轮轮推剧情，或者用快捷指令放养。60 多个字段的状态面板、角色卡、好感度、伏笔、时间线和分支、章节导航都在。存稿、存档、切档、导入老存档，随时能做。
- 看多层可缩放的舆图，看全世界地图一览图，看逐世界的原著地名对照，还能自己扩展资料库，做 DLC 大世界。
- 六个 AI 接口分工。主笔写正文，推演视线之外的远方事件，登记状态，插图，润色插图提示词，现实地球界的手机分身连微信和朋友圈。用哪个、混不混、留不留空，随你。
- 每界一份独立世界书，能增删改查、导出备份，九类模板填表就能生成条目。检索走 BM25、向量、精排，一级级往下退，哪一环挂了都不卡写作。
- 人物和关系这一块，有 NPC 编年史、亲密档案（兽形、半兽形、人形三态）、性格世界书和心理模型、动态关系、称号阁和装备词条，加成统一回灌到一个地方算。
- 逛二创。在云境内一键下载安装别人的 DLC、插件、资源包、存档、世界书、预设，也能把自己的改动打包发出去。安装就是三方合并加备份，随时能退。
- 跟常见前端工具互通。预设、正则、世界书整份导进导出，内置的云起预设支持一键云端同步。
- 怎么落地都行。从 GitHub 下载源码，Windows 双击 `start-windows.bat`，Mac 双击 `start-mac.command`，浏览器打开 `http://127.0.0.1:8080/` 就进开场封面。手机连同一个 WiFi，打开提示的网址，选「添加到主屏幕」，就是全屏 App，能离线跑 PWA。

再说一遍怎么启动，这几步容易踩坑。下载或克隆仓库之后，Windows 双击 `start-windows.bat`，Mac 双击 `start-mac.command`，然后浏览器开 `http://127.0.0.1:8080/`。也可以在任意平台跑 `python3 -m http.server 8899`，再开 `http://127.0.0.1:8899/opening.html`。直接双击 `index.html` 是打不开的，file 协议下 ES module 和 fetch 都会被 CORS 拦掉，必须走启动器用 HTTP 打开。细节在 [QUICKSTART.txt](QUICKSTART.txt)。

开场有四个入口。踏云开新档，续梦读档，观星调接口设置，造物进小云创造中枢，也就是 `xiaoyun.html`。第一次用，先去「观星」或者游戏里「☰ 工具 → ⚙ 接口设置」把自己的模型填进去。分发方式为什么改成这样，看 [DECISIONS.md](DECISIONS.md) 的 DR-001，造物入口为什么叫这个名字，看 DR-002。

## 四、边界，丑话说在前面

- 云境没有自己的服务器，零后端。所谓能联通的创意工坊文件夹，本质就是 GitHub 公共仓库里的 `community/works/` 目录。我们做到的是浏览、下载、安装全在云境内完成，你不用打开 GitHub 网页，底层还是走 GitHub，配了多线路容错和本机缓存。想要完全绕开 GitHub 又能让玩家互通，那就得加后端，跟零后端这个定位冲突，所以没做。
- 匿名读会撞 GitHub 的限流，实测大概每小时每 IP 60 次。我们做了多线路加缓存，第一次要联网，断网就读上次的缓存。
- 传二创必须用你自己的 token，这是 GitHub 写操作的硬性要求。fine-grained token 勾上 Contents 读写，或者用 classic 的 `public_repo`。token 只存本机，永远不进包。
- 跨层倍率是我们做的工程估算，不是原著里的数值，全部标了「估算，仅供校准」，不会写进正文冒充结论。
- 所谓「打包源码」，指的是你在云境里改过的那些内容层明文，manifest 加逐项 JSON，不是云境主程序的 `.js` 文件。网页读不到你设备磁盘上的源码文件，主程序归开发者。
- 项目只发源码和完整包，不出 APK，也不出安装包。大视频建议走外链，单个文件最好压在 20MB 以内，GitHub 的上限是 100MB。
