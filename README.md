# 云境 · AI 互动小说 + 开放世界扮演

> **一句话**：打开网页就能用的 AI 互动小说 + 开放世界扮演平台。纯前端静态站点，无构建、无后端、无账号；AI 接口由玩家自己填，故事与 API Key 只留在本机浏览器。

## 大致介绍

云境把「和 AI 一起写小说」和「跑一个会自己演化的世界」缝在同一个网页里。两条玩法共用一套引擎：

- **创作工坊**：设定视角 / 文风 / 时代 / 母题 / 开篇 / 技法 / 六维，与 AI 逐章共创，导出 TXT / Markdown。
- **开放世界扮演**：捏一个身份（姓名 · 出身 · 时代 · 资质 · 入场事件）踏进书里的世界自由漫游；身份三态 = 原著主角 / 原著配角 / 完全原创。

世界共 **38 个**：原著同人 30 · 真实地球 1 · 自由创作 6 · 原创网游大世界 1（寰宇纪元，由失落叶网游三部曲合流）。每个世界一份独立世界书 + 专名铁律表，按界考据，专治小模型写错原著人物、跳境界、凭空编宗门。

它不像普通聊天机器人「你问一句它续一段」：每一轮 AI 写正文的同时，背后有一整套状态、地图、人物、势力、账本在跑，并回过头注入下一轮主笔提示词。

## 特色

1. **世界自己会走**：世界时钟自转，NPC 的性格 / 理想 / 情绪按结仇、势力覆灭、共同记忆做有界低频因果迁移；势力兴衰、机缘、委托隔几天换一批；玩家的选择会回写进世界。
2. **按界考据**：38 界各自独立的世界书 + 专名铁律表，专治小模型写错原著人物、跳境界、凭空编宗门。
3. **数值白名单**：模型自编的等级 / 金币 / 经验会被确定性从正文剔除，玩家与 AI 看同一份账。
4. **不挑模型**：任意 OpenAI 兼容端点（官方直连 / 中转 / 自建网关 / 本地部署）都能填，零限制、零白名单；按接口特征与模型名初判档位，再按每轮真实输出双向升降档（连续稳定升全功能档，复读崩塌降求稳档），也可手动指定。
5. **六个接口各干各的**：主笔只写正文，状态登记、远方推演、插图、润色插图提示词、手机分身交给别的模型，成本自己配。
6. **不被锁住**：预设、正则、世界书、原创设定、存档都能导入导出；Key 不上传、不随存档导出；与 SillyTavern 整份互通。
7. **不用安装、断网也能跑的网页**，里面却跑着一整套会自己长大、还会记账的世界。

数据规模（2026-11-09 代码实跑）：38 界 / 世界书内置 **24,940** 条 / 玩家进界面板 **32,312** 条 / 通用常识库 194 条 / 专名铁律表 204 条 / 内置云起预设 **86 块** / 内置正则 **33 条** / 内置文风块 42 项。

## 能做什么

- 逐轮推进剧情或快捷指令放养；60+ 字段状态面板、角色卡、好感度、伏笔、时间线与分支、章节导航；随时导出存稿、存档、切档、导入老存档。
- 看**多层可缩放舆图**：地名不重叠，势力实时上图，玩家自建势力按驻地落图。
- 用**六个 AI 接口分工**：主笔写正文 / 推演视线之外的远方事件 / 登记状态 / 插图 / 润色插图提示词 / 现实地球界的手机分身（微信 · 朋友圈）。用哪个、混不混搭、留不留空，全随你。
- 用**知识库**：每界一份独立世界书，可增删改查、导出备份，九类模板填表生成条目，检索走 BM25 → 向量 → 精排并逐级降级，任一环挂掉都不卡住写作。
- **和酒馆互通**：整份导入 / 导出 SillyTavern 的预设、正则、世界书；内置云起预设支持一键云端同步。
- **怎么落地都行**：Windows / Mac 双击启动器；手机同一 WiFi 打开提示网址 →「添加到主屏幕」即全屏 App，可离线 PWA；另有独立安卓工程可出 APK。

**怎么用**：`python3 -m http.server 8899` → 浏览器打开 `http://127.0.0.1:8899/index.html`；Windows 双击 `start-windows.bat`、Mac 双击 `start-mac.command`。详见 [QUICKSTART.txt](QUICKSTART.txt)。首次使用进「☰ 工具 → ⚙ 接口设置」填自己的模型。
