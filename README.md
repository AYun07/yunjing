# 云境 · AI 互动小说 + 开放世界扮演

![云境封面](上架素材/商店宣传图-横版-封面.png)

> **一句话**：打开网页就能用的 AI 互动小说 + 开放世界扮演平台。纯前端静态站点，无构建、无后端、无账号；AI 接口由玩家自己填，故事与 API Key 只留在本机浏览器。唯一封面「万象入云」，四入口进入同一个世界。

## 一、云境是什么

云境把「和 AI 一起写小说」和「跑一个会自己演化的世界」缝在同一个网页里。两条玩法共用一套引擎，打开浏览器即可使用：

- **创作工坊**：设定视角 / 文风 / 时代 / 母题 / 开篇 / 技法 / 六维，与 AI 逐章共创，导出 TXT / Markdown。
- **开放世界扮演**：捏一个身份（姓名 · 出身 · 时代 · 资质 · 入场事件）踏进书里的世界自由漫游；身份三态 = 原著主角 / 原著配角 / 完全原创。

它不像普通聊天机器人「你问一句它续一段」：每一轮 AI 写正文的同时，背后有一整套**状态、地图、人物、势力、账本、时间线**在跑，并回过头注入下一轮主笔提示词。世界会自转，玩家的选择会回写进世界。

**世界共 38 个**：原著同人 30 · 真实地球 1 · 自由创作 6 · 原创网游大世界 1（寰宇纪元，由失落叶网游三部曲合流）。每个世界一份独立世界书 + 专名铁律表，按界考据，专治小模型写错原著人物、跳境界、凭空编宗门。

> **关于「36 界」这个数字**：代码里状态栏有 **36 套专属状态字段**，其余 2 个自由创作界（`free` / `freeworld`）不带固定题材、用通用字段即可。所以「38 个可进入的世界」与「36 界专属状态字段」并不矛盾——前者是世界总数，后者是有专属字段表的世界数。

## 二、特色特点

### 世界与考据

1. **世界自己会走**：世界时钟自转，NPC 的性格 / 理想 / 情绪按结仇、势力覆灭、共同记忆做有界低频因果迁移；势力兴衰、机缘、委托隔几天换一批；玩家选择回写进世界。
2. **按界考据 + 原著地点归位**：38 界各自独立的世界书 + 专名铁律表；原著势力/国家/宗门/地点/地区按原著方位与地理尺度归位到五级舆图，拒绝 hash 随机散点。附全世界地图一览图与逐世界原著地名对照表供核验。
3. **多层可缩放舆图**：地名不重叠，势力实时上图，玩家自建势力按驻地落图；五线深度下钻独立挂载，零侵入。

### 数值与战力

4. **数值白名单 + 默认卡死**：模型自编的等级 / 金币 / 经验会被确定性从正文剔除，玩家与 AI 看同一份账；严格演算模式是出厂默认，离谱上报被引擎真实截断，不靠模型自觉。
5. **玩家例外透明化**：玩家明确要求时可按轮放行，钳制从暗处搬到明处（可见提示 + 把拦截原因写回 AI，让它下轮别再犯）。
6. **跨层战力折算**：跨时代 / 多层体系（超神、道诡、帝霸、吞噬等副轴）可比较，折算规则与倍率全部标注「估算、仅供校准」写进报告，硬约束「不给跨层缘由一律判口胡」；嵌套宇宙用独立数据结构硬隔离副体系，避免混轴。

### 记忆与回档

7. **对话时光轴 + 任意楼层回档**：任意回合回档与重 roll；全量楼层快照让回到任意层时，所有随剧情演化的数据同步回滚，且回档可撤销。足迹 / 传承等跨层内容默认不回退，由玩家勾选决定——**星海纪行 1.7GB / 174 份全量快照无限追加的病根，云境不会得**。
8. **存档治理**：差分存档（结构化逐叶子 diff，本地全量 + 差分双模），gzip 压缩约 1/5 体积；固定 key 覆盖，不无限追加；带内存哨兵防膨胀。

### 模型与接口

9. **不挑模型**：任意 OpenAI 兼容端点（官方直连 / 中转 / 自建网关 / 本地部署）都能填，零限制、零白名单；按接口特征与模型名初判档位，再按每轮真实输出双向升降档（连续稳定升全功能档，复读崩塌降求稳档），也可手动指定。
10. **六个接口各干各的**：主笔只写正文，状态登记、远方推演、插图、润色插图提示词、手机分身交给别的模型，成本自己配。
11. **语义词缀引擎**：从固定词库查表升级为语意解读 + 情境涌现 + 玩家自定义；本地即时解读保底 + 大模型后台异步深度解读回填，全程走已治理的调用通道，成本与并发可控。

### 二创与工坊

12. **云境内创意工坊**：所有二创作品统一存于仓库 `community/works/` 单一总文件夹，每件一个带时间戳的子文件夹，内含 README.md（简介 / 特点 / 二创内容 / 打包源码四段）+ meta.json + package.zip；按时间倒序，云境内即可浏览、一键下载安装、发布，不用打开 GitHub 网页。旧 `packages/` 与 Issues 仅作历史只读，不写入也不删除。
13. **增量补丁 + 三方合并**：二创只打包「变化」——PatchEngine 生成增量补丁，安装走 base/ours/theirs 三方合并 + 自动备份 + 失败回滚，未涉及项沿用基线（作者没改的不算删除）；密钥在采集阶段全局剥离。
14. **小云造物中枢**：造物入口让小云按你的意志改源码、造文件、造模块、造插件、造 DLC、造原创设定并应用；造物工坊 / 文件桥 / 插件运行时 / 研发中枢四项直接用。

### 自由与边界

15. **不被锁住**：预设、正则、世界书、原创设定、存档都能导入导出；与通用前端预设格式整份互通；单档导出默认不带密钥（可选勾选明文以便换设备免重填）。
16. **零后端、Key 不上云**：无需安装、断网也能跑（PWA）；故事与 API Key 只留本机，上传二创需玩家自己的 token（只存本机、永不入包）。

> 数据规模（2026-11-09 代码实跑）：38 界 / 世界书内置 **24,940** 条 / 玩家进界面板 **32,312** 条 / 通用常识库 194 条 / 专名铁律表 204 条 / 内置云起预设 **86 块** / 内置正则 **33 条** / 内置文风块 42 项。
> 全功能实测（2026-11-20，38 界 × 每界约 10 轮真实对话，共 820 轮 / 1003 张截图）：灵宠、检定、成长账本、词语加成、语义引擎、称号、装备、战斗八大子系统 **38/38 全通过**，主要面板交互 38/38 全通过（详见 [功能可用性对照表](云境-功能可用性对照表.md)）。

## 三、能做什么

- 逐轮推进剧情或快捷指令放养；60+ 字段状态面板、角色卡、好感度、伏笔、时间线与分支、章节导航；随时导出存稿、存档、切档、导入老存档。
- 看**多层可缩放舆图**、全世界地图一览图，查看逐世界原著地名对照，玩家可扩展资料库（DLC 大世界）。
- 用**六个 AI 接口分工**：主笔写正文 / 推演视线之外的远方事件 / 登记状态 / 插图 / 润色插图提示词 / 现实地球界的手机分身（微信 · 朋友圈）。用哪个、混不混搭、留不留空，全随你。
- 用**知识库**：每界一份独立世界书，可增删改查、导出备份，九类模板填表生成条目，检索走 BM25 → 向量 → 精排并逐级降级，任一环挂掉都不卡住写作。
- 用**人物与关系系统**：NPC 编年史、亲密档案（兽形 / 半兽形 / 人形三态）、性格世界书与心理模型、动态关系、称号阁与装备词条，加成统一回灌单一真源。
- **玩二创**：在云境内逛创意工坊，一键下载安装别人的 DLC / 插件 / 资源包 / 存档 / 世界书 / 预设，也可把自己的改动打包发布；安装即三方合并 + 备份 + 可回滚。
- **和通用前端互通**：整份导入 / 导出通用前端的预设、正则、世界书；内置云起预设支持一键云端同步。
- **怎么落地都行**：从 GitHub 下载源码后，Windows / Mac 双击启动器以本地 HTTP 打开；手机同一 WiFi 打开提示网址 →「添加到主屏幕」即全屏 App，可离线 PWA。

**怎么获取并启动**：从 GitHub 下载或克隆本仓库 → Windows 双击 `start-windows.bat`、Mac 双击 `start-mac.command`，启动后浏览器打开 `http://127.0.0.1:8080/` 即进入**开场封面**；或任意平台执行 `python3 -m http.server 8899` → 打开 `http://127.0.0.1:8899/opening.html`。**直接双击 `index.html` 打不开**（file:// 下的 ES module / fetch CORS 限制），必须经启动器以 HTTP 打开。详见 [QUICKSTART.txt](QUICKSTART.txt)。

**开场四入口**：踏云（开新档）/ 续梦（读档）/ 观星（接口设置）/ 造物（**小云创造中枢** `xiaoyun.html`）。首次使用进「观星」或游戏内「☰ 工具 → ⚙ 接口设置」填自己的模型。分发方式变更见 [DECISIONS.md](DECISIONS.md) 的 DR-001，造物入口正名见 DR-002。

## 四、边界（如实说，不骗你）

1. **云境零后端，没有自己的服务器**。所谓「联通的创意工坊文件夹」本质是 GitHub 公共仓库里的 `community/works/` 目录。做到的是浏览 / 下载 / 安装全在云境内完成，不用打开 GitHub 网页；底层仍走 GitHub（多线路容错 + 本机缓存）。完全脱离 GitHub 的互通需要后端，与零后端定位冲突，未做。
2. **匿名读会撞 GitHub 限流**（实测约 60 次/小时/IP）。已做多线路 + 缓存；首次需联网，断网读上次缓存。
3. **上传二创必须玩家自己的 token**（GitHub 写操作强制认证），fine-grained 勾 Contents 读写或 classic `public_repo`；token 只存本机，永不入包。
4. **跨层倍率是工程估算，不是原著数值**，全部标注「估算、仅供校准」，不写进正文当结论。
5. **「打包源码」= 玩家在云境里改过的内容层明文**（manifest + 逐项 JSON），不是云境主程序 `.js`（网页读不到设备磁盘的源码文件，主程序归开发者）。
6. 项目只分发源码 / 完整包，不提供 APK / 安装包；大视频建议外链，包体单文件建议 < 20MB（GitHub 上限 100MB）。
