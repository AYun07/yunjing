关于「应用」——真实边界，不含糊

造物工坊 / 造新模块：小云按你的需求写出完整模块代码。点「挂载到大厅」即刻运行、刷新不丢；点「写入项目源码」需先用 Chrome/Edge 桌面版授权项目文件夹，她会把文件真实写进 modules/ 目录。

文件桥 / 改源码：授权本地项目目录后可读写 js/css/html/json 等文件，每次写入前自动备份、可回滚，并带语法自检。不授权也能用「导出补丁包」。

插件 / DLC / 原创设定：插件从授权目录被发现并挂到 7 个扩展点；DLC 激活后注入知识库参与创作；原创设定落成世界书条目。后两项在创作室完成，造物页一键直达。

关于大模型：让小云"按任意需求独立开发"需要你在工坊里填自己的模型接口与 Key；不填也能用内置模板体验完整流程。代码层无任何上传、无 git 操作，唯一外发是把你的需求文本发给你自己配置的模型。
