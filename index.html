使用指引
  • 创作工坊：完成故事设定（视角 · 文风 · 时代 · 母题 · 开篇 · 技法 · 六维），逐章共创
  • 扮演世界：捏一个身份（姓名 · 出身 · 时代 · 资质 · 入场事件），踏入原著开放漫游
  • 首次使用请点右上角「⚙」配置 AI 接口
  • 与 AI 逐轮推进，或点快捷指令放养续写
  • 满意即导出 TXT / Markdown 存稿
框架特性
  • 配置驱动：一个 config 文件定义一个文学世界
  • 设定台 60+ 选项：视角/文风/时代/母题全维可调
  • 开放世界扮演：原著知识库 + 原著忠实铁律 + 玩家身份卡
  • 变量系统：角色卡 / 伏笔 / 状态仪表盘全程追踪
  • 动态世界：第二 API 推演远方事件，NPC 档案自动并入
  • 变量AI：第三模型提取状态，主笔专注写正文
  • 双格式接口：OpenAI 兼容 / Gemini
  • 灵感引擎 + DLC 知识包 + 数据隔离存档
