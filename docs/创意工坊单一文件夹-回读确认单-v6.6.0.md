## 物理边界（如实披露，不混进"没问题"）

1. **云境零后端，没有自己的服务器**。所谓"联通的文件夹"本质是 GitHub 公共仓库里的一个目录。完全不经过 GitHub 的公共存储、又不加后端地让玩家互通，做不到。已做到的是：**浏览/下载/安装在云境内一站式完成，不用打开 GitHub 网页**；底层仍走 GitHub（多线路容错）。
2. **匿名读会被 GitHub 限流**（实测 IP 级 60 次/小时，raw 直连还超时；jsDelivr 对 1500+ 文件的大仓库返回 301 回 raw，不可靠）。因此清单读取走"Contents API 多线路 + 8 秒超时保护"，并缓存到本机；首次进入需联网，断网时读本机缓存。
3. **上传必须 token**。GitHub 的写操作强制认证，这是 GitHub 的规矩，不是云境能绕的。token 只存玩家本机，不进任何包体。玩家填一次即可长期用。
4. **包体体积**：GitHub 单文件建议 < 20MB（contents API 上限 100MB）。超大视频/图片走网盘外链，不静默失败。
5. **README.md / meta.json 是文本明文**（玩家可读可改）；package.zip 是真二进制 zip（contents API 传 base64→GitHub 存为二进制，下载得 PK 魔数字节，现有安装器已兼容）。
