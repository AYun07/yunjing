## 验收句（可验证）
- A1 每个新世界 KB 专题详录 ≥ 12 条新增有效条目，且均含原著具名锚点（人名/地名/道具名），不得编造。

- A3 圣堂雷光城方位矛盾消除（where 与 x 一致，原著无明文故以坐标为准改成"西部"）。
- A4 五轮实测循环，每轮从真机找问题并修复，终轮零问题；自检 ≥74/74，回归测试全绿。
- A5 每版 commit+tag+push、Release 上传两件套、SHA 自洽。
