# 云境 · 增量补丁与三方合并 设计契约 v6.5.0

## 0. 一句话目标
把二创从"整包收集"升级为"以官方最新版为基线、只传改动、下载端三方合并、装前备份可回滚、全类型统一采集"的增量同步体系；主线源码与开发者全程不参与。

## 1. 用户原话拆解（验收源）
1. 不能上传完整二创本体时，改为检测当前最新版云境，只把改动的地方打包上传。
2. 玩家下载后自动备份并覆盖对应文件。
3. 防止玩家之间版本不一致：该同步的同步、该覆盖的覆盖、该合并的合并。
4. DLC、插件、小云开发的工具、存档、预设、世界书、世界、新内容、资源包、图片、视频、文件等都能上传下载打包。
5. 主线仍是用户的，二创只在版块内流转。

## 2. 三条物理事实（决定方案）
见 `DECISIONS.md` DR-049 物理约束，及 `增量同步-需求回读确认单-v6.5.0.md` 第二节。核心：浏览器读不到磁盘源码文件（手机尤甚）、Gist 单文件约 100MB、存档常含密钥。

## 4. 数据契约

### 4.1 内容项 ContentItem
```js
{ key: 'preset/云起-暗夜', kind: 'preset', data: '<string|base64>', hash: 'a1b2c3d4', size: 1234 }
```
- `key`：`kind/<逻辑名>`，全局唯一。
- `hash`：FNV-1a 32 位，对 `data` 字符串计算；tombstone 删除项的 data 为固定串 `__YJ_TOMBSTONE__`。

### 4.2 基线清单 Baseline
```js
{ app:'yunjing', ver:'6.5.0', items:[{key,kind,hash}] }
```

### 4.3 增量补丁包 Patch Package（zip 内 manifest.json）
```js
{
  app:'yunjing-patch', schema:2,
  title, note, author, baseVersion, createdAt,
  license:'开源·非盈利',
  changes:[
    { op:'add'|'modify'|'delete', key, kind, baseHash, newHash, file:'content/0.json' }
  ],
  volumes: 1,            // 分卷总数
  containsSave: false,   // 是否含存档
  stripKeys: true        // 是否已剔除密钥
}
```
zip 结构：`manifest.json` + `content/<n>.json`（每项一个，data 存其中）+ 可选 `source/<path>`（源码级轨道）。

### 4.4 三方处置枚举
`sync` | `overwrite` | `keep` | `merge` | `conflict`

## 5. 核心算法（patch-engine.js）

### 5.1 hash(str)
FNV-1a 32 位：`h=0x811c9dc5; for c: h^=c; h=Math.imul(h,0x01000193)`，无符号输出 8 位十六进制。

### 5.2 diff(base, target) → changes[]
逐 key 求并集：base 无 target 有→add；都有 hash 不同→modify；base 有 target 无→delete；相同→不列。

### 5.3 plan(base, ours, theirs) → decisions[]
对每个 key，取 bh/oh/th（缺省视为 tombstone）：
- oh==th → `sync`
- oh==bh && th!=bh → `overwrite`
- th==bh → `keep`
- oh!=bh && th!=bh && oh!=th → 试 `merge3`；对象且可字段合并且无同键三方冲突→`merge`；否则 `conflict`
- 其余（理论上不会）→ `conflict`

### 5.4 merge3(b, o, t)
仅当三者都是可解析 JSON 对象时逐 key 递归：
- o==b 取 t；t==b 取 o；o==t 取 o；否则标记该 key 冲突。
- 数组/标量视为原子：相同取同值，不同且双方都改→冲突。
返回 `{ ok, value, conflictKeys[] }`。

### 5.5 备份与回滚
`makeBackup(decisions, ours)` → `{ at, entries:[{key,oldData}] }`，仅收录会被 overwrite/merge/apply-delete 的 key。
`apply(decisions, adapter)` → 逐 key 调 adapter.write（sync/keep 跳过）。
`rollback(backup, adapter)` → 逐 key 写回 oldData（delete 项恢复原值）。
备份栈固定上限 10，超出丢弃最旧。

### 5.6 版本检查 versionCheck(baseVer, ourVer, targetVer)
返回 `{ level:'ok'|'warn'|'block', msg }`：baseVer==ourVer→ok；不等但 targetVer==ourVer→warn（对方基于旧版）；targetVer 高于 ourVer 较多→warn 提示先升级。

### 5.7 分卷建议 suggestVolumes(totalBytes, limit=90MB)
`ceil(total/limit)`；返回 `{ count, needSplit, overCap }`（count>32 视为 overCap，提示网盘链接）。

## 6. 内容采集器清单（content-adapters.js）
| kind | 来源 | 写回 |
|---|---|---|
| dlc / plugin / tool / preset / worldbook / world / content | localStorage 前缀族 | 原键写回 |
| save | save-slots 导出结构（ls+idb） | save-slots 导入 |
| pack / image / video / file | IDB（file-bridge / 自建 blob store） | IDB put |
| source（可选） | FileBridge 读真实源码文件（桌面授权） | FileBridge.write + 自带 backup |

> 无法纳入的临时内存数据：适配器枚举时列入 `unscanned` 并在包内标注，不假装支持。

## 7. 安全
- 包体与 manifest 经 `scanSecrets`（复用并加强）：`sk-`/`ghp_`/`github_pat_`/`api_key=` 等命中即拦截；存档类默认 `stripKeys:true` 剔除密钥字段。
- token 只存本地，任何包/Issue 不携带。
- 含密钥存档仅允许私密 Gist（createPrivateGist），公开 Issue 只放"含私密存档包"提示 + 网盘/私信约定。
