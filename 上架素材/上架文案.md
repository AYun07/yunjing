> 万象入云，一念一世界——AI 互动小说与开放世界扮演。

## 应用描述（详情页正文）

云境是一款纯本地运行的 AI 互动小说与开放世界扮演平台。打开即入书，捏一个身份踏进 38 个世界自由漫游；世界时钟自行流转，NPC 性格与势力兴衰随你的选择而改变。

- **38 界开放世界**：原著同人、真实地球、自由创作、网游大世界，36 界专属状态字段。
- **活世界引擎**：世界时钟自转，NPC 因果迁移、势力兴衰、机缘委托隔期刷新，你的选择回写进世界。
- **按界考据**：每界独立世界书 + 专名铁律，专治模型写错原著人物、跳境界、乱编宗门。
- **五层长期记忆**：BM25 → 向量 → 精排逐级检索，剧情连贯不串档。
- **小云动态陪伴**：12 形态精修立绘 + 全预设动态动作，随你的话语切换情绪，零内置接口、本地播放。
- **隐私可控**：故事与密钥只存本机，纯前端架构，无需账号、无需服务器。

**注意**：云境本身免费，AI 功能需玩家自行配置 OpenAI 兼容的模型接口（Key 自带、按量自付）。无 Key 时所有本地功能（世界书、存档、地图、小云、导出导入）仍可正常使用。

## 隐私与权限说明（商店必填）

- **网络**：仅在你主动配置模型接口后，向你所填的端点发送剧情请求；未配置时零外网请求。
- **存储**：存档、设置与密钥仅保存在本机，不上传云端。
- **权限**：安卓端仅需存储权限用于导出/导入存档；不读取通讯录、短信、位置等无关信息。
- **付费**：应用本身免费，不含内购；模型 API 费用由你与模型服务商直接结算。
