# 云境 · 应用商店上架文案（v4.34.0）

## 一句话介绍（商店副标题，30 字内）

> 万象入云，一念一世界——AI 互动小说与开放世界扮演。

## 应用描述（详情页正文）

云境是一款纯本地运行的 AI 互动小说与开放世界扮演平台。打开即入书，捏一个身份踏进 38 个世界自由漫游；世界时钟自行流转，NPC 性格与势力兴衰随你的选择而改变。

- **38 界开放世界**：原著同人、真实地球、自由创作、网游大世界，36 界专属状态字段。
- **活世界引擎**：世界时钟自转，NPC 因果迁移、势力兴衰、机缘委托隔期刷新，你的选择回写进世界。
- **按界考据**：每界独立世界书 + 专名铁律，专治模型写错原著人物、跳境界、乱编宗门。
- **五层长期记忆**：BM25 → 向量 → 精排逐级检索，剧情连贯不串档。
- **小云动态陪伴**：12 形态精修立绘 + 全预设动态动作，随你的话语切换情绪，零内置接口、本地播放。
- **隐私可控**：故事与密钥只存本机，纯前端架构，无需账号、无需服务器。

**注意**：云境本身免费，AI 功能需玩家自行配置 OpenAI 兼容的模型接口（Key 自带、按量自付）。无 Key 时所有本地功能（世界书、存档、地图、小云、导出导入）仍可正常使用。

### 造物中枢 · 小云六项创造能力（v4.34.0 正名）

`xiaoyun.html` 是小云的**创造中枢**——让小云按玩家意志修改源码、创造内容并应用，能力均来自项目既有真实模块，本机执行：

| 能力 | 说明 | 落点 |
|---|---|---|
| 🛠 造物工坊 | 说需求→小云写完整模块代码→挂载大厅运行 / 授权后写入 `modules/` 源码 | 本页（XYDev） |
| 📝 文件桥 | 读写项目 js/css/html/json、写前备份、回滚、语法自检、`yj-patch` 补丁预览 | 本页（FileBridge） |
| 🔌 插件运行时 | 造插件、挂 7 个扩展点、从授权目录发现加载、隔离容错 | 本页（PluginRuntime） |
| 🔬 研发中枢 | 自主巡检、模块地图、改完自检、重构影响面分析 | 本页（MoDevtools） |
| 📦 DLC 工坊 | 造 DLC 知识包、导入导出、激活后注入知识库参与创作 | 创作室深链 `studio.html?goto=dlc` |
| ✨ 原创设计 | 八类模板造势力/人物/道具→世界书条目，AI 补稿、原创包搬家 | 创作室深链 `studio.html?goto=forge` |

真实边界：写入磁盘 / 文件读写 / 插件加载需 Chrome/Edge 桌面版授权项目文件夹；让小云「按任意需求独立开发」需在工坊填自己的模型接口与 Key（不填可用内置模板走完整流程）；代码层无上传、无 git 操作。小云形态与动态视频是本地预设陪伴形象，非创造能力主体。

## 隐私与权限说明（商店必填）

- **网络**：仅在你主动配置模型接口后，向你所填的端点发送剧情请求；未配置时零外网请求。
- **存储**：存档、设置与密钥仅保存在本机，不上传云端。
- **权限**：安卓端仅需存储权限用于导出/导入存档；不读取通讯录、短信、位置等无关信息。
- **付费**：应用本身免费，不含内购；模型 API 费用由你与模型服务商直接结算。
