一、你说的每一项，怎么修的

① 造物进去还是自由创作 + 工坊弹窗

真因：不是造物入口写错，而是本地内容目录 yj-content 残留旧文件，优先级高于打包新基线，服务器永远读旧的。之前我用"直接访问 URL"测，测的是新源码，没测到你实际读到的旧内容——这是我上一版判断失误的地方。

修复：装新版后若检测到基线版本高于 yj-content，自动用新基线原子重建本地内容目录（DR-109）。造物从封面点击直接进纯小云创造中枢，无自由创作界面、无叠加弹窗。

② 设置页只有主模型配置 / 全局开关点了没反应

源码里其实已有 5 个分区（模型配置、阅读外观、全局开关、存储与隐私、更新与公告），但你看到的是旧内容。实测深夜护眼/流畅模式/庆典特效点击都真实生效；只有"朗读正文"确实坏了——设置页没加载对应模块。已改成自包含实现（SpeechSynthesis 读本机最近一章），4 个开关现在全有效。

③ 角色塑造有两个地方，旧的还在

真因：wizard 模板里硬编码了 3 处旧角色塑造（都用 id=csWrap），和新助手 id 冲突，新助手的 mount() 一看 id 已存在就直接返回——新角色塑造从来没挂载成功，你一直看到的是旧的那个。已删除 3 处旧 UI，实测角色塑造入口从 2 个降到 1 个。

④ 选原著主角/配角，其余设定没跟着走

原来选立场只改一句提示文字，不填任何字段。已实现联动：选原著主角→姓名填韩立、身份/小传按原著；选原著配角→填该配角姓名、身份、性格（如墨彩环·聪慧倔强）、命运钩子。切换立场会清掉上一次的设定，不再混角。

⑤ 很多按钮按不动

真浏览器逐一点了 6 个页面 180 个按钮，异常 0 个。之前你点不动的按钮，多数是旧内容里的失效 UI；旧内容残留问题修复后，配合本轮修复，按钮全部可点。

⑥ 更新要能看到进度和具体错误

新增实时进度条：检查更新/同步内容时显示百分比 + 阶段（拉取清单/下载文件/校验/切换）+ 当前文件名；出错时列出具体是哪个文件、哪一步、什么原因，不再只有一句"失败"。实测进度条更新、错误详情展示全部通过。
