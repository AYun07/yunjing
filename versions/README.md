# 云境 · 历史版本归档

本目录按版本号归类存放历史源码快照、验收截图与过程文档。**当前可运行源码保持在仓库根目录**（PWA 入口需在根路径），不在此目录。

## 目录结构

```
versions/
├── vX.Y.Z/
│   ├── source-snapshot/   # 该版本的源码回滚快照（原 _bak_vXXX）
│   ├── screenshots/       # 该版本验收截图
│   └── docs/              # 该版本需求单/交付报告
├── _legacy-screenshots/   # 早期无版本号的验收截图
└── _reports/              # 跨版本的历史测试/预览报告
```

## 说明

- 归档前的精确路径映射见工作区 `../清理归档/仓库归档清单-20261125.json`（36→37 项 git mv，未删除任何文件）。
- 各版本**安装包**因超过 GitHub 单文件 100MB 上限，不进 git，见 GitHub Release（按 tag 归类）。
- 这里的 `source-snapshot` 仅作历史回查；不要在此运行，运行请用仓库根目录当前版本。
