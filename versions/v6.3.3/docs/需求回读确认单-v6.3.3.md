## 三、明确假设（不对就改这里）

- **A1 造物落点**：用户说"跳转到工坊那里"，判断为创作室原创工坊面板（`studio.html?goto=forge`），而非小云造物中枢介绍页。若用户其实想要介绍页，改一行 TARGET 即可。
- **A2 续梦形态**：做成封面上的"读档浮层"（与踏云选择器同风格），不新建独立页面——更符合"点一下直接看到存档"、无页面闪烁。
- **A3 存档可见范围**：只列"确实有存档正文"的档位（空档不列为可读项），避免玩家点进去发现是空的。
- **A4 守卫强度**：按用户目的——防小白误开，不防懂代码的人。故用「会话令牌 + 带参数放行 + 同源放行 + 显式 dev 开关」；不按 hostname 一刀切（小白的启动程序也用 localhost，按 hostname 放行会让守卫失效）。
