## 4. 真实 API 测试：**本轮未重跑（如实披露）**

v3.89.0 曾用用户提供的真实 API 完成 33 界结构 33/33、真实生成 33/33（50,276 字）、
深度旅程 10/10、应用内子系统 6/6、专项 60/60、接口矩阵 5/6（2 项供应商侧异常）。

**本轮改动不触及创作室、业务模块与 API 调用链，因此未重复消耗真实 API 全量回归**，
沿用 v3.89.0 的结论，不把它冒充为本轮结果。若需要本轮口径的全量真实 API 回归，可另行执行
`live-full.mjs all --conc=2`。

## 5. 未验证项（强制披露）

- SW 离线真机未测：本地 `http://localhost` 不满足 `https:` 注册条件，仅做静态清单校验。
- 未逐文件人工审查全部源文件；本轮覆盖大厅真实生效路径。
- `MoAssistant` 的 `#moDrawer` 抽屉仍保留为 AI 管家聊天面板（非浮动第二只小云）。
- 旧 `mo-*` 兼容层 / `.mc-*` 死样式因 20+ 业务模块依赖其 API 保留。
- 中间宽度（768/1024）、320px 极窄屏、iPad 竖屏未逐一实拍。
- 真实 API 全量生成本轮未重跑，理由见第 4 节。
