## 未验证项（强制披露）

- **Service Worker 离线真机验证未做**：本地 `http://localhost` 不满足 `studio.html` 的 `https:` 注册条件，SW 不注册；只做了静态清单校验（319 条路径 200、引用零缺失）。PWA 断网实测需在 HTTPS 环境进行。
- **未逐文件人工审查全部源文件有效性**：通过 33 界结构扫描、33 界真实生成、263 个 JS 语法检查、63 项一致性自检、专项冒烟覆盖真实生效路径，但未对仓库每个文件逐一给出有效性结论。
- **`MoAssistant` 的 `#moDrawer` 抽屉仍保留**为 AI 管家聊天面板（非浮动第二只小云，`💬 AI 管家` 按钮打开）。若「只能有一个全功能小云」的口径要求连抽屉 UI 也并入 `#xyBuddy`，需后续迁移 `quickActions` 与聊天渲染。
- **旧 `mo-*` 兼容层、`moshu` 兼容分支、`css/base-style.css` 中 `.mc-*` 死样式未全量删除**：因 20+ 业务模块依赖 `MoStore.getItem` / `MoChibi.say` / `MoAssistant.send` 等 API，保留为兼容层。
- **PWA 安装后图标实测未做**（本地无 HTTPS），仅 HTTP 200 与清单引用校验。
